# BAO STORE
Website bán hàng demo chạy bằng HTML, CSS và JavaScript.

## Chạy trên VS Code
1. Giải nén thư mục.
2. Mở thư mục `bao-store` bằng VS Code.
3. Mở `index.html` bằng Live Server hoặc nhấp đúp để mở bằng trình duyệt.

## Đưa lên GitHub Pages
Tải lên toàn bộ 3 file `index.html`, `style.css`, `script.js` ở thư mục gốc repository.
Vào Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Lưu ý
Đây là bản demo frontend. Tài khoản, giỏ hàng và đơn hàng được lưu trong LocalStorage trên trình duyệt hiện tại. Mật khẩu không được bảo vệ như hệ thống thật; thanh toán chỉ mô phỏng, không thu tiền. Không dùng dữ liệu cá nhân hoặc thanh toán thật trên bản demo.
